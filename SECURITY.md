# Security Policy

## Supported Versions

Security fixes are considered for the current `0.1.x` pre-release line.

## Reporting a Vulnerability

Report suspected vulnerabilities through
[GitHub Private Vulnerability Reporting][private-report]. This private channel
is enabled for the `ARCH-runtime` repository and is the supported reporting
path for security issues.

Do not disclose suspected vulnerabilities through public issues, pull requests,
or discussions. Maintainers will coordinate assessment, remediation, and
disclosure with the reporter through the private advisory.

[private-report]: https://github.com/erikmktdig-cell/ARCH-runtime/security/advisories/new
