# Security Policy

## Supported Versions

Security fixes are considered for the current `0.1.x` pre-release line.

## Reporting a Vulnerability

The intended private channel is
[GitHub Private Vulnerability Reporting][private-report], but it is not active
until the remote `ARCH-runtime` repository exists and its repository setting is
enabled. Until activation is verified, this project has no valid private
reporting channel and release publication is blocked.

Do not disclose suspected vulnerabilities through public issues, pull requests,
or discussions. Once the private channel is active, maintainers will coordinate
assessment, remediation, and disclosure with the reporter.

[private-report]: https://github.com/erikmktdig-cell/ARCH-runtime/security/advisories/new
